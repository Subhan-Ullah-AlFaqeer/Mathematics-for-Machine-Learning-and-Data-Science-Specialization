After completing this course, you will be able to:

    1.Perform gradient descent in neural networks with different activation and cost functions
    2.Visually interpret differentiation of different types of functions commonly used in machine learning
    3.Approximately optimize different types of functions commonly used in machine learning using first-order (gradient descent) and second-order (Newton’s method) iterative methods
    4.Analytically optimize different types of functions commonly used in machine learning using properties of derivatives and gradients.
